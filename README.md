# Micrositio · Premio de Cuento y Poesía FLC 2026

Micrositio para presentar las dos obras ganadoras del **Premio de Cuento y Poesía de la Feria del Libro Colima 2026**.

## Obras

| Género | Título | Autora |
|--------|--------|--------|
| **Poesía** | *La grieta por donde nació el mundo* | Ana Luisa Flores Madrigal |
| **Cuento** | *Tundra en verano* | Angelina del Refugio Llerenas Hurtado |

## Colores diferenciados

- **Poesía**: tonos verdes (portada lima)
- **Cuento**: tonos lilas/violetas (portada lavanda)

## Cómo publicar en GitHub Pages

1. Crea un repositorio nuevo (público).
2. Sube todo el contenido de esta carpeta (`index.html` + carpeta `assets/`).
3. Ve a **Settings → Pages**.
4. En *Source* selecciona la rama `main` (o `master`) y carpeta `/ (root)`.
5. Guarda. En unos minutos estará disponible en `https://tu-usuario.github.io/nombre-repo/`.

## Funcionalidades

- Portadas de ambos libros
- Dos fragmentos por obra (modales)
- Botones de **descarga directa** de los PDF completos
- Semblanzas de las autoras
- Diseño responsive con colores diferenciados (verde = poesía, lila = cuento)
